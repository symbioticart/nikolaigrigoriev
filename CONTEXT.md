# nikolaigrigoriev.com — как устроен сайт

Сайт художника Николая Григорьева. Показывает живые работы: каждая рисуется день
за днём из записи одного тела по неизменному правилу.

Файл описывает устройство. Что делать при поломке — `docs/RUNBOOK.md`. Как
добавить работу — `docs/ADDING-A-WORK.md`.

## Работы

Все описаны в одном месте — `works.json`. Оттуда их берут страницы, сервер,
правило и утренний рисовальщик. Работа = запись в реестре + `art/<id>/painter.js`.

| id | Название | Видна |
|---|---|---|
| `87` | Variations 87 | да, на главной |
| `89` | Variation 89 | да, на главной |
| `archipelago` | Archipelago | нет — обкатывается вживую |

## Запись тела

Кольцо Oura. Сервер тянет историю раз в 6 часов и складывает её в **постоянный
диск** (`ARCHIVE_DIR=/var/record/archive`, том `record` на Render). Записанный
день неизменяем: он пишется один раз и больше не переписывается — на этом стоит
закон работы. Копия записи каждый день уезжает на домашний сервер
(`/srv/dataroom`, таймер `record-backup.timer`, 04:30).

Без токена сервер поднимается на вшитом снапшоте и честно говорит `live: false`.

Наружу отдаются только каналы — `/data/days.json`, `/89/data.json`. Сырых
показателей тела сайт не отдаёт никогда.

## Что видит зритель

Главная и страницы работ показывают **готовые картинки** — `state/<id>.webp`,
последний записанный день, без выцветания. Движок (p5 + p5.oil) не нужен, чтобы
увидеть работу; он просыпается позже и только чтобы листать дни.

Тишину рисует браузер вживую: `filter: grayscale()` плюс слой цвета грунта,
непрозрачность обоих — из `art/silence.js` по `meta.gapDays`. Поэтому выцветание
не может отстать от записи: оно не запекается в картинку.

Тишина начинается со второго дня: цвет уходит к 14-му, изображение — к 30-му.
Форму работы тишина не трогает.

## Сервер

`server.js`, ноль зависимостей в рантайме. Кроме раздачи: синхронизация с Oura,
телеграм-оповещения и вечерний дайджест, приём заявок WIT36, `/lab`,
ежедневный кадр `/89`.

Общая голова страниц (иконка, карточка для ссылки) пишется сервером при отдаче —
один источник, без шага сборки. Заголовки: CSP без внешних источников,
`Permissions-Policy` отказывает камере, микрофону, месту.

## Проверки

- `npm test` — законы работы и поведение сервера (`test/laws.test.js`,
  `test/server.test.js`). Ловит, в частности, работу без художника и
  переписывание прошлого.
- `scripts/smoke.js` — прогулка по живому сайту браузером.
- Конвейер (`.github/workflows/ci.yml`): пуш в `staging` → репетиция;
  пуш в `main` → прод, прогулка, при провале — откат и телеграм.
- Репетиция: `nikolaigrigoriev-staging.onrender.com`, вход по паролю
  (`STAGING_AUTH`), `noindex`. Токенов кольца и телеграма там нет намеренно.

## Ограничения, которые не обсуждаются

1. Прошедший день не перерисовывается никогда.
2. Ноль npm-зависимостей в рантайме.
3. Ни один показатель не читается обратно из картины.
4. Тишина не двигает ни одного мазка.
